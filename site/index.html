Quickstart

From clone to agent
in three commands.

Bring your own E2B, GitHub, Notion, and Nebius credentials. An OpenAI key enables optional SDK traces. Secrets stay in your local .env.

  1. 1
    CloneGet the source from GitHub
  2. 2
    ConfigureAdd service credentials
  3. 3
    RunLaunch the sample task
# Clone and install
$ git clone https://github.com/tirth1263/docker-e2b-mcp-agent.git
$ cd docker-e2b-mcp-agent
$ uv sync
# Create your secret file
$ cp .env.example .env

# Then add your API tokens to .env
# Validate, inspect, automate
$ uv run main.py --check-config
$ uv run main.py --list-tools
$ uv run main.py
